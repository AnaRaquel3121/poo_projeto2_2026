+----------------------------------------------------------+
|                     CLASSE Simulacao                     |
|                                                          |
|  - eventos: queue<Evento>                                 |
|  - sensores: vector<Sensor*>                             |
|  - comandoAlarme: ComandoAlarme*                          |
+----------------------------------------------------------+
|  + Simulacao()                                           |
|  + ~Simulacao()                                          |
|  + adicionarSensor(sensor: Sensor*) : void               |
|  + setComandoAlarme(comando: ComandoAlarme*) : void      |
|  + iniciar(ficheiroEventos: string) : bool                 |
|  + executar() : void                                     |
|  + obtemSensor(id: int) : Sensor*                         |
+----------------------------------------------------------+
              | comp 1..1 |             | comp 1..n
              v           v             v
    +-------------------+  +-----------------------------------+
    |   ComandoAlarme    |  |         CLASSE Sensor             |
    |                    |  |                                   |
    |  - estado: bool    |  |  - id: int                        |
    |  - senha: string   |  |  - divisao: string                |
    |  - mensagem: string|  |  - estado: bool                   |
    |  - estadoCampainha |  |  - tipo: TipoSensor               |
    |  - tentativas: int |  |  - comando: ComandoAlarme*        |
    |                    |  |                                   |
    +-------------------+  +-----------------------------------+
    |  + MAX_TENTATIVAS  |  |  + Sensor(id, div, tipo)          |
    |  + ComandoAlarme() |  |  + setComando(cmd) : void         |
    |  + armar(senha)    |  |  + ativar() : void                |
    |  + desarmar(senha) |  |  + desativar() : void             |
    |  + mudarSenha()    |  |  + notificar() : void             |
    |  + ativarCampainha |  |  + fixaEstado(estado) : void      |
    |  + pedirSenha()    |  |  + getId() : int                  |
    |  + liga()          |  |  + getDivisao() : string          |
    |  + desliga()       |  |  + getEstado() : bool               |
    |  + getEstado()     |  |  + getTipo() : TipoSensor         |
    |  + getCampainha()  |  |  + getTipoString() : string       |
    |  + getMensagem()   |  +-----------------------------------+
    |  + getTentativas() |  
    +-------------------+  
              ^                    
              | assoc n..1         
              |                    
              +--------------------+

+----------------------------------------------------------+
|                    STRUCT Evento                         |
|                                                          |
|  + tipo: string                                          |
|  + param1: string                                        |
|  + param2: string                                        |
+----------------------------------------------------------+

+----------------------------------------------------------+
|                    ENUM TipoSensor                       |
|                                                          |
|  INTRUSAO                                                |
|  MOVIMENTO                                               |
|  FOGO                                                    |
|  GAS                                                     |
|  INUNDACAO                                               |
+----------------------------------------------------------+

+----------------------------------------------------------+
|                    RELACOES                               |
|                                                          |
|  Simulacao -[comp 1..1]-> ComandoAlarme                  |
|  Simulacao -[comp 1..n]-> Sensor                         |
|  Sensor -[assoc n..1]-> ComandoAlarme                   |
+----------------------------------------------------------+
